This tutorial covers both user-level theme changes and developer-level theme creation.

## 1. Change the active theme from admin

1. Open `/admin/theme`.
2. Browse installed themes.
3. Click `Activate` on the theme you want.
4. Click `Save changes` to commit the selection.

Important:

- Activation changes local draft state first.
- Nothing is committed until you click `Save changes`.

## 2. Customize theme variables

1. Click `Customize` on a theme card.
2. In the drawer, edit fields defined by the theme schema.
3. Click `Save` or `Save changes`.

Theme fields can be:

- `string`
- `boolean`
- `number` (with min/max/step)
- `select`

All values are stored in `public/site/settings.json` under:

```json
{
  "theme": {
    "active": "minimal",
    "vars": {}
  }
}
```

## 3. Preview theme changes safely

Two preview options are built in:

- `Live preview`: opens site in a new tab with `?preview=true`
- `Auto preview`: continuously writes preview settings while you edit

`Clear preview` removes preview state from local storage.

## 4. What actually gets committed

Theme changes commit the settings file:

```text
public/site/settings.json
```

Commit message used by admin:

```text
chore: update theme settings
```

## 5. Add a new theme (developer workflow)

### Step A: Create theme folder

Create a new folder, for example:

```text
src/themes/my-theme/
```

### Step B: Export a theme module

`src/themes/my-theme/theme.ts`

```ts
import type { ThemeModule } from "@/core/domain/types"
import { Home } from "./pages/Home"
import { Post } from "./pages/Post"

export const myTheme: ThemeModule = {
  id: "my-theme",
  schema: {
    title: "My Theme",
    fields: [
      { key: "brandName", label: "Brand name", type: "string", default: "My Blog" },
      { key: "layout", label: "Layout", type: "select", options: ["compact", "wide"], default: "compact" },
    ],
  },
  defaults: {
    brandName: "My Blog",
    layout: "compact",
  },
  render: { Home, Post },
}
```

`src/themes/my-theme/index.ts`

```ts
export { myTheme as theme } from "./theme"
```

### Step C: Register the theme

Edit `src/core/domain/themes/registry.ts` and add it to `THEMES`.

### Step D: Validate

Run:

```bash
npm run validate:themes
```

Validation checks:

- theme folder has `index.ts` or `index.tsx`
- exported `theme` exists
- `theme.id` matches folder name
- schema/defaults consistency
- required render components

## 6. Common pitfalls

- Theme appears in code but not admin: it is not added to `registry.ts`.
- Theme vars reset unexpectedly: schema keys changed and old keys are now unknown.
- Validation failure: `theme.id` does not match folder name exactly.
