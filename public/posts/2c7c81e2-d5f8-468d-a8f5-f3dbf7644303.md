This guide explains how BlogHub media management works end to end.

## 1. Open the media manager

Go to `/admin/media`.

You can:

- upload files
- search/filter/sort media
- view where files are used
- edit or delete files

## 2. Upload media files

You have two options:

1. Click `Upload` and pick files.
2. Drag and drop files onto the page.

Uploaded files are committed immediately to GitHub under:

```text
public/media/<filename>
```

## 3. Handle filename conflicts

When a filename already exists, BlogHub asks what to do:

- `Rename`: creates a unique new filename (`name-2.ext`, etc.)
- `Replace`: overwrites the existing file at the same path
- `Cancel`: aborts upload

## 4. Insert media into a post

1. Open `/admin/posts/<post-id>`.
2. In the markdown editor toolbar, click the image icon.
3. Pick media from the library.
4. BlogHub inserts markdown.

For images and GIFs:

```markdown
![image](/media/file.png "image")
```

For non-image files, BlogHub inserts a link.

## 5. Use media in settings and frontmatter

You can set logo, favicon, or featured images with media paths, for example:

```text
/media/logo.png
```

Places where this is used:

- `/admin/settings` for logo and favicon
- post frontmatter field `featured_image`

## 6. Edit existing images

On `/admin/media`, click `Edit` on image-like files.

The built-in editor supports:

- crop
- zoom
- rotate
- reset/clear

Saving commits the updated file back to the same media path.

## 7. Delete media safely

Click `Delete` on a media item.

If the file is referenced by posts, BlogHub shows those post IDs before confirmation.

After delete:

- the media file is removed from the repo
- references inside posts are not auto-rewritten

You should update affected posts manually.

## 8. Generated media index behavior

Admin pages read media metadata from:

```text
public/generated/media-index.json
```

After media changes, update generated files by either:

1. Running `npm run generate`, or
2. Letting the `Regenerate content (develop)` workflow commit generated updates on `develop`.

## 9. Recommended conventions

- Use lowercase, hyphenated filenames.
- Keep media organized by purpose (hero images, logos, etc.).
- Prefer modern formats (`webp`, `avif`) when possible.
- Replace large files with optimized versions to keep repo size manageable.
